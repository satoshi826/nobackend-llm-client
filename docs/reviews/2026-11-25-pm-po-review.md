# プロダクトレビュー（PM/PO 視点）— 2026-11-25

> サブエージェント（Fable）によるレビュー。コードとドキュメントを読んだうえでの評価で、実機での動作確認はしていない。
> 補足（メイン担当より）: 「`navigator.storage.persist()` を呼んでいない」という指摘は誤りです。起動時の `init()`（`src/state/app.ts`）で呼んでいます。ただし、拒否されたときに画面で再要求する導線がない点は、そのとおりです。

## 1. ポジショニングとターゲットへの適合

**強み**
- 価値の伝え方が初回の画面に出ている（`ChatView.tsx` の `ProviderChooser` / `KeySetup`）。「サーバーなし・会話はこのブラウザだけ・解析なし」と明記している。
- 送信先の透明性が競合より高い。
  - プライバシータブに送信先の表がある。
  - モデルに private / 外部中継のバッジが付く。
  - 接続先ごとの一言説明がある（Gemini 無料枠では学習に使われること、DeepSeek は中国で処理されること）。
- キー金庫・CSP・利用上限つきキーの案内（`KeyPanel.tsx`）で、BYOK への不安に正面から答えている。

**導入や信頼を妨げるもの**
- 「誰のためのアプリか」がアプリ内に書かれていない。初回の画面に、どの接続先を選ぶべきかのおすすめがない。
- キーを手に入れるまでの導線が弱い。各社の管理画面へのリンクも、キーなしのデモもない。最初の 1 通を送るまでに、接続先の選択 → 外部でキー発行 → 貼り付け → パスフレーズの案内、の 4 段階がある。
- 配布された版を検証できない。アプリ内にバージョンやコミットの表示がなく、Service Worker は黙って更新する。
- UI が日本語だけ（README は 3 か国語あるのに）。
- 6 つの接続先が、本物のキーで確かめられていない。

## 2. 機能のレビュー

**強いところ**
- 会話ツリー、別のモデルで再生成、会話の圧縮、キャッシュの表示、使用量タブ。
- ツールの承認（`save_skill` は毎回確認）と、パスフレーズ 1 つでキー・会話・画像をまとめて暗号化する設計。
- 画像生成がひと通りそろっている（同じシード・新しいシード、高解像度化、編集、背景の除去、ギャラリー、拒否されたときの提案）。セーフモードが既定でオン、ツールが既定でオフかつ確認制なのも妥当。

**わかりにくい・ちぐはぐなところ**
- 画像モード中も、ヘッダーにはチャットのモデルと private の印が出たまま。実際に使う画像モデルが外部中継でも気づきにくい。
- `generate_image` ツールが、画像バーの前回の設定（モデル・スタイル）を黙って使う。承認カードにモデル・外部中継かどうか・費用の目安を出すべき。
- セーフモードの切り替えは「設定 → チャット → 画像」の奥にある。ぼかされた結果から直接たどれない。
- 画像の費用表示が正確でない。プロンプトの自動補強の追加料金が見積もりに入っておらず、背景の除去は費用がわからない。計上されない差額が残高の警告の誤報につながる可能性がある。
- 画像を 1 枚ずつ削除できない（会話ごとにしか消せない）。
- 返信候補が既定でオンかつ会話と同じモデルを使うので、高いモデルでは黙って課金が増える。
- スキルの仕組みは、このアプリの利用者にはやや大げさ。保存済みプロンプトやペルソナのほうが直感的に価値が伝わる。

**この利用者層にとって、あって当然の機能で欠けているもの**
- 添付と画像の入力（画像に対応したモデルが絞り込みに出るのに、画像を送れない）。
- 生成パラメータの画面（思考の深さ・最大トークン数・top_p）。
- 会話 1 つだけの書き出し、暗号化したバックアップ。
- 自動のタイトル付け、タグ・フォルダー、キーボードショートカット。
- 回答の「続きを生成」、承認待ちの再開。

## 3. リスク

- **データの消失**: 保存先がオリジンごとなので、URL が変わると見えなくなる。パスフレーズを忘れるとすべて消える。バックアップは暗号化されない。画像を含めると、大きなファイルを 1 回で作るのでメモリが足りなくなる可能性がある。
- **プライバシーの説明**: 暗号化している人が、暗号化されていないバックアップを手元に置くことになる。使用量・設定・モデル名は暗号化されないことが、画面に書かれていない。
- **思わぬ費用**: 返信候補、思考の送り返し、自動の要約、画像の複数枚・高解像度が重なる。予算の上限がない。Venice 以外は単価が取れない。
- **法律・利用規約**: 規制の少ないテキストや成人向けの画像を扱うのに、年齢の確認、注意書き、各社の利用規約へのリンクがない。公開インスタンスを運営する人の責任の範囲を明文化すべき。
- **サポートの負担**: CORS、広告ブロッカー、Cloudflare が差し込むスクリプト、保存領域の分割、パスフレーズ忘れ、本物のキーで確かめていない接続先。

**やるべきでないこと**
- 実行時に UI から任意の接続先を足すこと（キーの送り先をビルド時に固定する安全性が崩れる）。
- 同期・アカウント・共有のためのバックエンド。
- ロールプレイやキャラクター機能。
- 匿名でもテレメトリを送ること。
- 画像の接続先を今のうちに増やすこと（先に P0 を固める）。
- MCP やコードの実行を先にやること。

## 5. バックエンドなしで測れる成功の指標

- 手元だけで出す統計（利用した日数、会話の数、パスフレーズの有無、最後にバックアップしてからの日数）と、利用者が任意で貼れる「匿名のまとめをコピー」。
- モックを使った E2E テストで、最初の回答までのクリック数と秒数を測る。少人数のユーザーテストで、キーを手に入れてから最初に送るまでの完了率を測る。
- Cloudflare 側の集計（リクエスト数、`/vault/` の割合）と、GitHub の star・fork・issue。
- issue の分類の割合、本物のキーで確かめた接続先の数。
